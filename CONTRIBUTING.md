# Contributing

Thanks for your interest in improving DriverSafe.

1. Fork the repository.
2. Create a focused branch: `git checkout -b feature/your-change`.
3. Install dependencies with `pip install -r requirements.txt`.
4. Add or update tests for behavior changes.
5. Run `python -m unittest discover -s tests -v`.
6. Commit with a clear message and open a pull request.

Please do not submit personal video recordings or images of people without their informed consent. Avoid claims that the prototype is safety-certified or prevents accidents.
